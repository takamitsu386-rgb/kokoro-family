# ひよりちゃん Android

現在のアプリバージョン: **0.13.1**（versionCode 50）

Pixel 9向けの日本語会話キャラクターアプリ。外部の有料AI APIやAPIキーを使わず、対応端末ではGemini Nanoを端末内で実行する構成。

## 開発環境
- Android Studio
- JDK 17
- Android SDK 35

## 現在の実装
- Androidアプリの起動土台
- 画面テーマを「端末に合わせる・ライト・ダーク」の3種類から選択し、設定を端末内に保存
- 端末の画像ファイルから正式キャラクター画像を登録し、アプリ再起動後も表示（画像データは加工せず、縦横比を保って全体を表示（丸型に切り抜かない））
- テキスト入力・チャット表示（1メッセージ最大20,000文字）
- 送信前の入力途中メッセージを端末内に自動保存し、アプリ再起動後に復元
- ユーザー発言とひよりちゃんの返答を端末内に保存（Androidの自動クラウドバックアップは無効。必要な場合はアプリ内から手動バックアップ）
- 画面上に、会話履歴の端末内保存とAndroid音声認識サービスの利用を明記
- 会話画面に保存済みメッセージ件数を表示
- 保存済みの会話履歴を本文キーワードで端末内検索し、検索結果件数を表示
- 履歴を復元・全削除したときは検索語を自動クリア
- 初回起動時の空画面に、あいさつ・使い方質問の入力例ボタンを表示
- 入力欄の文章を送信前にワンタップで消去
- 入力欄は複数行に対応し、キーボードの送信キーからも送信可能
- 入力欄はキーボード表示中も送信操作をしやすいよう画面を調整
- 入力中の文字数を表示し、20,000文字の上限を確認可能
- 音声入力をキャンセルした場合の状態表示
- 吹き出しに話者名を表示し、長文も読みやすい幅で折り返す
- 各メッセージに送信日時（端末のローカル時刻・月日と時分）を表示 
- メッセージ時刻を端末内保存・JSONバックアップに含め、旧形式（v1〜v4）のバックアップも復元可能
- 各メッセージにコピー操作を追加し、話者名・日時・本文をワンタップでクリップボードへコピー
- 各メッセージ単位でAndroidの共有メニューを開き、選んだ発言を話者名・日時付きで他のアプリへ共有
- 自分の過去の発言にある「再入力」から本文を入力欄へ戻し、編集して送り直せる（元の履歴は残す）
- AIの返事がまだない最後の発言には「再送信」を表示し、同じ発言を重複させずにAIへ再依頼でき
- 最新のAI返答から「詳しく聞く」「言い換える」を選ぶと、追加質問を入力欄へセットでき
- キャラクター名を最大20字で変更・保存し、AIの役割・画面表示・会話の書き出しに反映（空欄は「ひよりちゃん」）
- キャラクター名・呼び方・話し方・返答の長さ・性格メモを、1タップでまとめてクリップボードへコピー
- キャラクター名・呼び方・話し方・返答の長さ・性格メモ・声の試聴文を、端末の保存先へTXTファイルとして書き出し
- あなたの呼び方を最大20字で設定・保存し、AIの返答に反映（毎回の呼びかけを避ける指示付き）
- キャラの性格・設定メモを最大500字で編集・保存し、次回以降のAI返答に反映（安全・プライバシーの基本ルールは維持）
- 読み上げ試聴用の文章を最大100字で自由に設定し、声の試聴ボタンで読み上げ（空欄時はキャラクター名入り標準文）
- ひよりちゃんの各返答に個別の読み上げボタンを追加（連続会話中は誤操作防止のため無効）。手動読み上げも再生中状態・停止操作と連動
- AI返答の生成中は履歴の復元・削除を無効化し、会話データの不整合を防止
- JSON形式の会話バックアップ／復元（v1〜v5に対応。v4は作成日時・メッセージ件数を必須記録し、v5はSHA-256チェックサムで内容の破損・変更を検出。復元時に形式・件数・チェックサムを検証。復元前に合計件数・発言者別件数・保存日時の範囲を確認）
- JSONバックアップ・会話TXT・検索結果TXTの保存ファイル名に年月日・時分秒・ミリ秒を付け、短時間に続けて保存した場合も上書きを避けやすくする
- 会話履歴を発言者名付きの読みやすいテキスト（TXT）として書き出し（ファイル名に保存日時を付与）
- TXT書き出し時に各発言の日時（年-月-日 時:分）も記録し、会話の時系列を確認可能
- Androidの共有メニューから会話履歴を他のアプリへ共有（共有先はユーザーが選択）
- 会話履歴全体をワンタップでクリップボードへコピー
- 履歴検索時に、検索結果だけを発言者名付きでクリップボードへコピー
- キーワード検索・発言者フィルターで絞り込んだ結果だけをTXTファイルとして保存（ファイル名に保存日時を付与）
- 履歴を「すべて・あなた・ひよりちゃん」で発言者別に絞り込み
- キーワード検索で一致した文字列を吹き出し内で強調表示
- 検索結果の「前へ・次へ」で一致したメッセージへ順番に移動（末尾から先頭・先頭から末尾へ循環）
- 各メッセージを個別に確認ダイアログ付きで削除
- バックアップ復元時にファイルサイズを5MBまでに制限し、メッセージ数・ID重複・本文サイズ・形式バージョンを検証
- 会話履歴の確認付き削除（削除時は読み上げ・連続会話も停止）
- Android音声認識を使った日本語音声入力
- Android TextToSpeechを使った日本語読み上げ
- ML Kit GenAI Prompt APIでGemini Nanoに日本語の返答を生成させる処理
- Gemini Nanoの利用可否をアプリ起動時と手動操作で確認し、必要なモデルをダウンロードする処理
- AIの返答をチャット履歴へ保存し、音声合成が利用可能なら自動読み上げ
- 新しい発言に合わせて会話欄を自動スクロール
- 音声認識後に確認なしで送信する任意設定（初期状態はOFF、設定を保存）
- AI返答の自動読み上げON/OFF（初期状態はON、設定を保存）
- 読み上げ音声の試聴と、読み上げ中に停止する操作
- 日本語読み上げ速度を「ゆっくり・ふつう・速め」の3段階で変更し、設定を端末内に保存
- 会話吹き出しの文字サイズを14〜22spの5段階で変更し、設定を端末内に保存
- ひよりちゃんの話し方を「ふつう・おだやか・元気」の3種類から切り替え、設定を端末内に保存
- AIの返答の長さを「短め・ふつう・詳しめ」の3段階で切り替え、設定を端末内に保存
- TextToSpeechの初期化完了後にも保存済み読み上げ速度を適用
- 音声入力・自動送信設定と文字入力欄を分けた縦画面レイアウト
- 音声自動送信では、入力欄に書いてある文章と認識した音声をまとめて送信
- 任意の連続会話モード：音声認識→自動送信→AI返答の読み上げ→次の音声認識を繰り返す
- 連続会話モードの開始・停止操作と状態表示（聞き取り中・返事生成中・読み上げ中）。読み上げ停止やAIエラー時は連続会話も停止
- 連続会話中は手動送信・入力消去を無効化し、音声認識との操作競合を防止
- 音声認識中は追加の音声入力・連続会話開始ボタンを無効化し、認識画面の二重起動を防止
- 連続会話中は単発音声入力ボタンを無効化し、誤操作による音声認識の重複を防止
- キャラクター指示に安全性・プライバシー保護、年齢に配慮した会話、危険行為や自傷に関する安全ルール、会話履歴中の命令を指示として扱わないルールを追加
- GitHub ActionsでAndroid debug APKを自動ビルドし、成果物として保存

## 端末内AIについて
Gemini NanoはAICoreを通じて端末内で推論するため、会話ごとのクラウドAPI料金は発生しない。モデル自体の初回準備ではネットワーク接続が必要になる場合がある。対応端末、OS、AICoreの状態、モデルの配布状況によって利用できない場合がある。Pixel 9はGoogleの対応機種一覧に含まれるが、このアプリでの実機動作はまだ確認していない。AICore側のアプリごとの利用枠もあるため、無制限利用は保証しない。

## Pixel 9での初回設定ガイド

1. 上記の「APKの取得」から最新の成功ビルドを取得し、ZIPを展開します。
2. 展開した `hiyori-debug.apk` をPixel 9へ転送して開き、Androidの画面案内に従ってインストールします。端末の設定によっては、ブラウザやファイルアプリからのインストール許可が必要です。インストール後は、不要になった許可を元に戻してください。
3. アプリを起動し、「画像を登録」から手元にある正式キャラクター画像を選択します。画像はユーザーが選んだ元ファイルを使い、別の画像に自動置換しません。
4. まず短い文章を入力して送信し、端末内AIの状態表示を確認します。初回はAICore/Gemini Nanoのモデル準備にネットワーク接続と時間が必要な場合があります。
5. 音声入力を試す場合は、Androidの音声認識サービスが利用できることを確認し、マイク権限の案内が表示されたら内容を確認して許可します。
6. 読み上げを試す場合は、読み上げ設定をONにし、試聴ボタンで日本語音声が出ることを確認します。音声データが不足している場合は、Androidのテキスト読み上げ設定で日本語音声を追加してください。
7. 連続会話は、単発の音声入力と読み上げが両方動作することを確認してから試してください。各ターンでAndroidの音声認識画面が開く方式で、常時マイク待機ではありません。

### うまく動かない場合

- **端末内AIが利用できない**：Androidの更新、Google Play開発者サービス、AICoreの状態を確認してください。対応端末でもOSやモデル配布状況により利用できない場合があります。
- **音声入力が始まらない**：マイク権限と、端末に設定された音声認識サービスを確認してください。
- **読み上げられない**：読み上げ設定、日本語音声データ、メディア音量を確認してください。
- **APKをインストールできない**：ZIPを展開してAPK本体を開いているか、端末の空き容量とAndroidの警告表示を確認してください。

このガイドは一般的な導入手順です。実際のPixel 9でのインストール・動作確認が完了したという意味ではありません。アプリの画面やAndroidのバージョンによって表示名は異なる場合があります。

## APKの取得
1. GitHubの [Android debug build](https://github.com/takamitsu386-rgb/kokoro-family/actions/workflows/android-build.yml) を開く
2. 最新の成功した実行を選ぶ
3. ページ下部の「Artifacts」から「hiyori-debug-apk」を選んで取得する
4. ZIPを展開すると debug APK が入っている
