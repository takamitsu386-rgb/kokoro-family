# ひよりちゃん Android

Pixel 9向けの日本語会話キャラクターアプリ。完全無料を目標とし、有料API・課金登録を必須にしない。

## 開発環境
- Android Studio
- JDK 17
- Android SDK 35

## 現在の状態
- Androidアプリの最小起動土台を追加
- テキスト入力・表示画面を追加
- 送信したテキスト会話を端末内のSharedPreferencesに保存し、次回起動時に読み込み
- JSON形式で会話履歴を書き出し・読み込みするバックアップ／復元機能を追加
- アプリ内から会話履歴を確認ダイアログ付きで削除可能
- 日本語の音声入力を追加。Androidの音声認識画面を呼び出し、認識した文章を入力欄へ入れる
- Android TextToSpeechを使った日本語音声のサンプル再生ボタンを追加
- AI会話、AIの返答読み上げ、元のキャラクター画像は未実装
- APKのビルド・Pixel 9実機テストは未実施

## バックアップ
チャット画面上部の「バックアップ」でJSONファイルとして保存し、「復元」でそのJSONを読み込む。復元すると現在の端末内履歴はバックアップ内容に置き換わる。

## 音声機能
入力欄の「音声」を押すとAndroid側の音声認識機能が開く。認識された文章は送信前に入力欄へ入り、内容を確認してから送信できる。「声を試す」はAndroidのTextToSpeechで日本語の短いサンプルを読み上げる。音声データの有無や読み上げ品質は端末の音声設定に依存する。

## 注意
端末内AIは対応状況・モデル提供・利用上限に依存する。無料・無制限・常時利用を保証しない。元のキャラクター画像は提供された正式素材のみを使用する。
