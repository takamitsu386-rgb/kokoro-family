# ひよりちゃん Android

Pixel 9向けの日本語会話キャラクターアプリ。完全無料を目標とし、有料API・課金登録を必須にしない。

## 開発環境
- Android Studio
- JDK 17
- Android SDK 35

## 現在の状態
- Androidアプリの最小起動土台を追加
- AI会話、音声入出力、履歴DB、バックアップ、元のキャラクター画像は未実装
- APKのビルド・Pixel 9実機テストは未実施

## 注意
端末内AIは対応状況・モデル提供・利用上限に依存する。無料・無制限・常時利用を保証しない。元のキャラクター画像は提供された正式素材のみを使用する。
